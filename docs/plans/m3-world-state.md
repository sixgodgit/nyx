**M3：动态世界实施方案**

进度以 [PLAN.md](../../PLAN.md) 为准；当前仅规划。计划分支：`codex/m3-world-state`。执行前置：M1、LANG 及稳定的 M2 任务上下文。

目标：在一个可重放的动态找物任务中，验证长期记忆能降低寻找成本，并正确处理状态过时与不确定性。

| 子任务 | 实施方案 | 验收 |
| --- | --- | --- |
| M3-01 | 选一个仿真环境；冻结感知、规划、工具、任务与预算 | 比较无记忆、近期上下文、词法/向量基线、当前 Nyx 与新状态投影 |
| M3-02 | Entity / Observation / State，绑定身份、位置参照、坐标版本及时间 | 语言表述与实体身份分离；相似对象或重识别歧义不盲目合并 |
| M3-03 | 维护最后确认、新鲜度、不确定性、冲突及重新观察建议 | 区分最后见到/当前确认/推测/未知；遮挡不被等同于不存在 |
| M3-04 | 重放移动、遮挡、失联、传感器冲突与更正场景 | 搜索耗时、重复搜索和成功率改善，且不增加无依据的确定判断 |

Nyx 引用感知器、地图和坐标变换版本，通过适配器协作；感知/SLAM/高频控制各自负责其职责。高频流使用容量与保留策略，长期保留关键事件和证据片段。

状态查询在证据不足时返回不确定性与重新观察建议。记录足够的证据以区分感知错误、身份关联错误、陈旧记忆与规划错误。原文/观测与派生状态可分别纠正、重算和遗忘。

先仿真、后实机；模块关闭时恢复既有文本/情景检索。M4 依赖该阶段提供的状态版本及结果观测，不能只凭工具报告假定行动成功。
