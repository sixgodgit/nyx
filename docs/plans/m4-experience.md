**M4：经验闭环实施方案**

进度以 [PLAN.md](../../PLAN.md) 为准；当前仅规划。计划分支：`codex/m4-experience`。执行前置：M3 可提供可追溯的状态与行动后观测。

目标：让已发生的行动结果形成带适用条件的经验，并通过留出任务验证收益。

| 子任务 | 实施方案 | 验收 |
| --- | --- | --- |
| M4-01 | Episode / ActionAttempt / Outcome，关联目标、起始状态、预期、执行及观测 | 事件链可重放，动作报告与独立结果证据分开 |
| M4-02 | 经验候选包含前置条件、参数、环境/执行器版本及失败分类 | 检索次数不冒充成功证据；失败能区分感知、记忆、规划、工具和执行 |
| M4-03 | proposed → validated → persisted → activated；支持失效、撤销与依赖删除 | 已验证提案不冒充已生效知识；原始证据变化向经验传播 |
| M4-04 | 固定任务条件下进行留出评测与消融 | 在未用于提炼的场景提升结果，报告失败率、成本及适用边界 |

同一证据经多个索引、摘要或梦境处理后仍视为同一来源，不能累加成独立确认。相关性和一次成功不直接证明因果或通用技能。

复用现有巩固/快照模块；情绪、熟悉度和梦境的额外成本通过消融决定。候选隔离、重算与回退保留来源及删除规则；停用错误经验不删除原始经历。

M5 只共享已声明权限、版本和失效规则的对象，不将未经验证的经验自动扩散到其他设备。
